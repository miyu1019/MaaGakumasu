# HIF 使用与构建

## 配置

运行包中的 HIF 固定本战、跳过选偶像，默认集中、一次培育、不使用体力药、不跳过准备。新解压目录首次打开只有「一键培育」实例和「HIF培育」任务，任务选项沿用维护者已确认的测试设置；模拟器连接需要自行设置。

公开首次启动模板位于 `extensions/hif/first-run/`：`config/config.json` 是界面设置，`config/instances/hif.json` 是不含设备信息的 HIF 实例和任务选项，`resource/mfa_layout.json` 是界面布局。构建时复制到新运行包；手动更新已有版本时保留整个 `config/` 和本地 `resource/`，不会用模板覆盖个人配置。

五个面板分别维护出牌、获取卡、换出卡、饮料、技能卡定制。公共默认值仅包含集中职业的现有策略，其他职业保留空表。首次初始化从 `extensions/hif/defaults/` 复制到 `config/hif/`；文件已存在时不覆盖。

## 旧版迁移

1. 关闭旧前台，保留旧目录，在新目录解压安装包。
2. 复制原来的 `config/instances/` 及 `config/config.json` 到新目录。定时任务和连接配置仍属于个人设置，迁移前自行核对。
3. 旧版文件若直接位于 `config/`，将自己的 `cards_priority.json`、`hif_drink_profiles.json`、`hif_custom_card_selection.json` 复制到新目录 `config/hif/`。
4. 在新目录执行 `.\python\python.exe tools/hif_app.py migrate`。工具先备份，再转换旧条目与图片路径，保留任务顺序、勾选、备注和适用选项；初/NIA 条目不转换。重复执行不重复迁移。
5. 若已使用独立 HIF 版本，直接保留自己的 `config/`，无需再次转换。

手动检查和更新只读取 `miyu1019/MaaGakumasu` 的 HIF Releases，不读取原作者仓库，也不自行同步上游。更新需要对应日期版本的完整 Windows x64 ZIP 和同名 `.zip.sha256`。通过校验后，仅替换 HIF、包内上游脚本、组合入口及说明；整个 `config/` 和前台、Python、MaaFramework 保留。更新成功后重启前台；失败自动恢复原脚本。

如果新包的前台补丁、Python 依赖或固定运行时版本改变，请将完整包解压到新目录，再复制自己的 `config/`。兼容检查会拒绝将这种新包装入正在使用的旧前台。

## 维护者同步上游

原作者更新由维护者在 GitHub 或本地自行同步到 Fork，再将需要的上游提交合入 `hif-independent`。同步时保持 `extensions/hif/` 独立，修改 `hif-release.json` 的 `upstream_commit` 为选定提交，并让原版 `agent/`、`assets/` 与该提交一致；构建工具按该提交导出。完成兼容验证后更新日期版本号，发布新的 HIF ZIP 和 SHA-256。只同步 Git 分支不会让客户端安装更新；客户端只认本 Fork 的 HIF 发布包。

## 可重建输入

| 部件 | 固定版本 |
| --- | --- |
| 上游脚本 | v1.5.1，`3fde881ee8a87335067a76cd0ffe563ac74aa30c` |
| 前台 | v2.14.0，`16378c2a5219d7050a4b43e90629f89c146ee464` |
| MaaFramework / Python maafw | 5.12.3 |
| Python | 3.12.9，Windows x64 嵌入版 |

下载来源与 SHA-256 在 `hif-release.json`，Python 依赖版本在 `requirements-hif.txt`。HIF 完整补丁包含五个面板及全部独立任务支持；不依赖发布者的前台工作目录，也不提交前台完整源码副本。

安装 Git、Python 3.12.9（含 pip）与 .NET SDK 10，在具有完整 Git 历史的本仓库检出中执行：

```powershell
python tools/hif_build.py build
python tools/hif_verify.py
python tools/hif_build.py package
```

运行目录为 `build/MaaGakumasu-HIF`。构建不会覆盖已有运行目录；需要重新组装时，请先将本次生成的目录移到自己的备份位置，再构建。原版 `agent/` 与 `assets/` 保持不变，构建按固定提交导出；这两个目录被修改时拒绝打包。

## 发布

HIF 专用工作流只处理 Windows x64，支持手动构建与 `vYYMMDD.序号` 标签发布，例如 `v261008.1`。同一天的新构建递增序号；版本标签必须与 `hif-release.json` 相同。发布前运行完整本地检查，推送和远程发布需仓库拥有者明确确认。

源代码许可证及依赖原有许可证保持原样。感谢 MaaGakumasu、MaaFramework 与 MFAAvalonia 原作者。安装包仅附 HIF 扩展与运行所需部件，不包含个人日志、备份或连接信息。
