# MaaGakumasu-HIF v261015.2

本次更新修复 HIF 满栏饮料操作误停、定制后购饮余额识别，以及中场说明误触发回忆生成识别的问题。

## 更新内容

- **满栏饮料操作**：修复详情已经关闭却被判为失败的问题。容忍文字识别框的轻微横向变化，点击取消后单独计算关闭确认时限，并在超时后再次复核领取页状态。保留连续画面确认、重试上限和安全停止机制。
- **购饮余额识别**：支持合并同一行紧邻的数字框，并通过连续两帧金额一致确认余额，减少刷新后偶发识别失败导致的提前结束购饮。保留 50 P 购饮门槛。
- **回忆生成识别**：修复中场说明文字误触发回忆生成识别的问题，同时确认 `MEMORY` 标题及“生成”按钮后再处理。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
