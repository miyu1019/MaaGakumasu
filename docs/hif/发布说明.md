# MaaGakumasu-HIF v261008.2

Windows x64 独立 HIF 培育版本，修复战斗选卡循环、停止任务时闪退和实时画面问题。

- 选中的目标卡仍可确认出牌，邻近手牌偶尔漏检不会反复选择同一张卡。
- 停止任务时等待正在执行的原生操作结束，再释放 Agent 和 HIF 资源。
- 实时预览独立刷新，避免额外 MuMu SDK 连接；旋屏后允许画面尺寸变化并清除旧画面，预览失败可重连，持续主截图失败有明确停止提示。
- 饮料详情关闭后确认战斗页或选卡页稳定再继续，并检查使用后数量减少；两次无法关闭会保存本地诊断图并停止。减少使用后的重复等待。
- 连续确认只有不可用牌时提前跳过；无法可靠识别时保留 15 秒自动 SKIP，饮料弹窗期间不会出牌或跳过。
- 保存已有任务列表后，重开或重新加载资源不会补回其他任务，仍可手动添加。配置串行保存、临时文件替换，失败保留原文件并提示。
- 减少识别日志噪声，修复边缘识别区域越界；更新托盘、标题栏和可执行程序图标，减少留白并加大标题栏图标。

HIF 固定本战、跳过选偶像，沿用游戏中已选偶像。首次只有「一键培育」实例和「HIF培育」任务，默认集中、一次培育、不使用体力药、不跳过准备；五个配置面板仅预置集中策略，其他职业为空白模板。

本版前台补丁已改变，升级请将完整 ZIP 解压到新目录，完全退出旧前台后复制自己的 `config/`；界面布局可一并复制 `resource/mfa_layout.json`。模板不会覆盖已有配置。旧版本的手动脚本更新会因前台不兼容而提示使用完整包，不会强行覆盖。

保留原版 MaaGakumasu v1.5.1 培育实现，固定 MFAAvalonia v2.14.0、MaaFramework 5.12.3 和 Python 3.12.9；上游仍由维护者自行同步。此版本不自动检查或安装更新。附带 ZIP 和 SHA-256 校验文件。

最新一轮在 MuMu 完成两场战斗及指定培育次数，正常退出。演出旋屏仍可能出现短暂截图重试；其他模拟器、汉化及 DMM 的完整流程尚未验证。
