# MaaGakumasu-HIF v261101.1

本次更新加入游戏跨日自动恢复、新强化卡与强気/全力指针状态条件，修复相谈误识别，并将多处“等待超时即停止”改为观察后继续。

## 更新内容

- **跨日自动恢复**：游戏跨日回到标题时，中断当前动作，重新登录后从主界面继续育成，不新开育成。
- **新卡**：加入「獲物はあなた+」「結果としての今+」「ファンが望むこと+」，并补齐卡图。新卡需在面板中自行导入，识别与定制菜单尚未经实机长流程验证。
- **条件优先级**：全力与強気职业新增「指针状态」条件，可勾选全力、強気、温存；強気职业也可设置条件关系。
- **相谈**：修复离店后剧情台词「……相談させてほしい。」被误认成相谈按钮、导致停止的问题；入店前饮料页处理较久时，不再随即判定商店超时。
- **本战用饮**：饮料演出较长时，不再因详情关闭慢而停止，也不会重复点「使う」。
- **饮料所持上限页**：点残す后场景过渡较长时，继续等待，不再停止；仍不补点。
- **超时处理**：页面、动画或场景过渡超过等待时间时，改为不点击、观察最多 90 秒，确认到已知画面后继续培育，同一步骤最多 3 次。购买、定制、舍弃饮料、中场回血等消耗操作结果不明时，仍保留现场停止，不重复执行。
- **手牌识别**：补认手牌时改用新截图重新检测。
- **其他**：清理不再使用的流水线节点与旧出牌分支，技能卡定制目录改用官方 ID。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
