# MaaGakumasu-HIF v261101.2

本次更新修复培育收尾的几处停止问题，改进出牌时的手牌识别，新增复制卡事件与再抽选开关，并加入更新渠道选择。

## 更新内容

- **培育收尾**：最终评价、回忆照片页在入口恢复中能被确认，不再安全停止；结尾演出未被识别时，由「プロデュース評価」结果页的「完了する」接上培育结束流程，回到主页。
- **竖屏演出**：模拟器卡顿未转横屏时，按竖屏演出等待播放结束，不点跳过；培育结束流程超时放宽到 180 秒。
- **出牌**：看详情后抬起的牌遮住带建议光效的邻牌时，按原卡位补回该牌并可正常选中打出，不再卡住或漏打高优先级牌。
- **战斗日志**：内容不变的出牌决策、手牌与使用限制不再重复记录，变化时注明省略次数；最后一回合过场跳过上限提高到 15 次。
- **再抽选**：授业与支给再抽选分别加开关，与游戏内共用次数，识别不到「再抽選」按钮即停止；点击后先确认候选卡已刷新再读卡名，通信卡顿时不再读到上一轮的旧卡名。
- **复制卡事件**：按优先获取名单选卡，沿用删卡页的核对与确认流程。
- **授业交换**：卡组超过三行时滑动扫描全卡组，并复核卡名；停止任务时不再继续点卡。
- **饮料所持上限页**：扫描时比对图标，提交前轻量核对，滚动条到底即停，整体提速；图标被 i 角标压低得分时也能认定，未匹配图标会保存裁图便于排查。
- **相谈商店**：不购买也不删卡时，确认终了按钮后直接退出。
- **更新**：设置中可选更新渠道，「正式版」跟随稳定 Release，「测试版」跟随 nightly 预发布（仅 Windows x64）；下载源只保留 GitHub。更新器替换文件遇到瞬时占用时会退避重试。
- **前台**：移除运行指示等循环动画，避免持续重绘占用核显拖慢模拟器。

竖屏演出、遮挡补回与培育结果页接续均依据当日 MuMu 实测日志修复；竖屏演出判定规则来自单次实测样本，如仍遇到演出期间停住，请保留 `debug/` 日志反馈。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
