# MaaGakumasu-HIF v261011.2

本次更新增加一战饮料用量控制，整理各面板布局与独立使用说明，并完善未配置卡片偏好、补给动画跳过及通信错误恢复。

## 一战饮料控制

- 各饮料分别设置「一战使用」和「二战使用」，默认均开启；两项都关闭时保留原「不使用」行为，不领取、购买或使用该饮料。
- 每种饮料可设置一战最多使用 0～4 瓶，默认不限量；二战不受一战限瓶影响。
- 支持未配置饮料的一战使用开关及统一单项上限，并可设置所有饮料合计的一战总上限；默认全部不限量。
- 定时使用、组合使用和关联卡片出牌前使用共用计数，避免多个入口绕过上限。
- 面板统一同行字号及控件大小，以紧凑分栏展示一战、二战及购买设置；使用时机和关联卡片放在购买下方。

## 面板使用说明

- 技能卡优先级、饮料、技能卡定制、授业换出、删卡及关联规则等面板的说明独立为「使用说明」窗口。
- 说明按功能分块、标题加粗，并分别解释按钮与选项；打开说明后仍可操作原面板。

## 未配置卡片偏好

- 按职业设置未配置卡片偏好：不偏好、精神卡、主动卡，或按剩余回合切换前后期偏好；支持优先强化版本，并随优先级配置分享。
- 强化版本以实际卡名识别结果为准，保留手动优先级、条件优先级及使用限制的作用顺序。

## 流程恢复

- 补给动画逐次点击并重新检查奖励页面，减少等待，同时避免进入选卡或饮料领取页后继续点击。
- 通信错误须同时确认错误提示和重试按钮，在当前步骤内恢复；购买、删卡及定制操作不会因恢复而重新执行。

## 验证情况

- 已通过：完整育成流程、一战饮料单项与总量限制、二战饮料使用、旧配置兼容、面板设置保存、独立说明窗口及完整包更新与回滚。
- 尚未实机覆盖：全部职业、全部饮料与卡片组合，以及通信异常恢复场景。

## 升级注意：前台与更新脚本需配套

- 如果旧运行包曾单独替换支持安装进度的新前台，但仍保留旧版更新脚本，点击「更新 HIF 完整包」可能在倒计时结束后失败，提示「独立安装程序未就绪，当前程序保留」。新版包可能已经下载，但尚未安装。
- 原因是新前台传入 `-ShowProgress` 参数，旧版 `tools/hif_update_runner.ps1` 不支持该参数而立即退出；这是前台与脚本版本不匹配。本次完整发布包中的更新脚本支持该参数。
- 遇到此问题，请完全退出旧前台，运行 `export_settings_导出设置.bat` 备份个人设置，将备份 ZIP 另存到旧目录之外；下载本页完整包并解压到新目录，在新目录运行 `import_settings_导入设置.bat` 导入备份，再启动新版。不要只替换前台 EXE/DLL；确认设置恢复后再处理旧目录。
- 如果已下载新版并由维护者协助修复原目录，还需同步本次更新暂存目录中的 `hif_update_runner.ps1`；只替换运行包 `tools/` 下的脚本，已准备的更新仍可能继续使用旧脚本。
