# MaaGakumasu-HIF v261105.1

本次更新改进本战饮料栏的瓶数识别，修复满栏换饮料时取消按钮不点击、保留页卡组不满一屏时卡住，以及旧版技能卡定制配置导致面板无法打开的问题，并同步五张卡的正式名称。

## 更新内容

- **本战饮料**：饮料栏按固定四槽汇总多帧识别瓶数，空槽另用空杯轮廓确认，修复浅色边框饮料（如ジンジャーエール）时有时无导致瓶数少算、用后等待超时的问题；用后核对少一瓶且剩余饮料从左连续，同名饮料多瓶同样适用；瓶数无法确认时本回合不用饮料，不会误点。
- **满栏换饮料**：取消按钮的「×」图标时而被并入文字识别框，按钮位置因此始终判为不稳定而不点击，现改为按右边界判断稳定，修复持有饮料详情无法关闭、最终超时停止的问题。
- **保留/移动页**：点到末行空位即视为卡组到底，不再下滑；修复卡组不满一屏时下滑无法确认位移、放弃选卡后卡住至安全停止的问题。
- **技能卡定制**：兼容 v261015 保存的临时项目 ID，修复旧配置导致技能卡定制面板无法打开的问题；面板保存时写回官方项目 ID。
- **卡牌目录**：同步 5 张卡的正式名称（初めての場所+、初めてのご褒美+、愛を込めて+、月明かりに包まれて+、夢と現の境界線+），卡牌 ID、图片与定制项目不变。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
