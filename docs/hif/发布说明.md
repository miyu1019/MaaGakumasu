# MaaGakumasu-HIF v261103.1

本次更新新增全力/強気卡牌的「保留」选择，改进出牌时的手牌识别与授业换出的卡组扫描，选卡页跳过不可选的卡和空位，并修复部分环境下检查更新失败的问题。

## 更新内容

- **保留**：出牌优先级面板中全力/強気卡牌可勾选「保留」，职业顶部可开启「按优先级保留」（默认关闭，先找到先保留）；职业配置分享文件同步包含保留名单，旧文件按空名单导入。
- **保留/移动页**：按来源选卡（全力/強気打出的卡或正在使用的饮料），ほっと緑茶按保留名单选卡，本領発揮+ 最多选两张、都未找到时点取消；卡组超过一屏时慢速滑动扫描整个卡组，选中前滚回并复核卡名。
- **出牌**：查看详情补认手牌后先取消选中，等手牌回到原位再识别，避免抬起的牌遮住邻牌、残缺手牌被当作整手决策。
- **授业换出**：卡组滚动按整个重叠区确认位移，滑动改为约一行，无法确认时滑回顶部；空位不再点开，也不再按上一张卡名记录。
- **复制卡事件**：跳过变暗的不可复制卡，不再点开读名；名单未命中时改选第一张可复制的卡。
- **删卡事件 / 相谈删卡**：跳过卡组末尾的空位。
- **检查更新**：HTTPS 只使用 Windows 受信任根证书校验，修复部分环境下检查更新报 `unable to get issuer certificate` 的问题。

保留选择、手牌取消选中依据 MuMu 实测日志修改；复制卡暗卡跳过沿用技能卡定制页的灰态判定，删卡页空位判定沿用授业换出的规则，尚未在这两个页面实机验证，如遇选错卡请保留 `debug/` 日志反馈。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
