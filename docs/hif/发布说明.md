# MaaGakumasu-HIF v261009.3

本版汇总 2026-10-09 的 HIF 配置与培育更新。使用 Windows x64 完整包升级，保留个人职业策略、实例、连接和窗口布局。

## 卡牌组合与饮料关联

- 特製ハツボシエキス支持关联多张 A 卡：普通策略选中目标后，先喝一瓶再出这张卡；组合衔接时保留配对饮料。关联期间不参与普通定时用饮，清除关联后恢复原时机。
- 任意起始卡可配置有序后续候选，包括国民与脚光等组合。每组独立设置等待 0～6 回合、是否使用初星黒酢、成功后再次等待，以及后续卡「正常出牌／首次组合前保留／只用于衔接」三种用法。
- 等待只统计实际空过，重复起始卡可重置等待；每轮衔接最多用一瓶初星黒酢。严格衔接模式不会被普通兜底绕过，成功记录在每场战斗结束后清空。
- 删除任务级「国民脚光等待回合」，备份并迁移为组级设置。同职业旧值冲突时在面板选择，不静默覆盖；明确保存空组合表示关闭。
- 后续卡与关联卡导入支持筛选、分页和统一排序；候选名称在配置窗口查看。后续卡按钮与使用限制放在同一行，减少卡牌行高度。

## 优先级、回合识别与培育修正

- 条件优先级扩展到全部职业，支持剩余回合 ≥／≤ 和闭区间；全力职业保留全力值条件。
- 使用限制增加「有额外回合时不使用」：左上角还有白底蓝字「+N」时保留该卡，8/+1 和 1/+1 均适用。额外回合储备独立识别，处理倒计时 1 转入额外回合的状态变化。
- 无 SP 课程时按配置的属性优先级选择。授业只在日期和三列按钮确认后进入并计数，修复开局及转场误识别。
- 支给卡只读取标题行卡名，排除效果、类型、费用与装饰文字，连续确认后匹配获取名单。
- 普通饮料领取页满 4 瓶时，先识别待领取目标，再逐瓶识别手持饮料，舍弃最低优先级的非目标；舍弃确认后重新选中目标领取。勾选式所持上限页仍使用独立流程。
- 饮料详情返回、舍弃和确认按钮均等待位置连续稳定；确认详情关闭后才点下一瓶。同名确认未生效时有限重试，明确未舍弃则取消并拒领本次饮料；结果不明时返回失败，避免错误追加操作。
- 移除旧「默认不拿饮料」的读取和节点，领取按职业饮料面板决定；相谈及定制后购买开关保留。
- 本战再挑战的分数读取区域覆盖完整四人顺位列表。
- 新增强化卡「悪戯ハートジャック+」「無自覚チャーム+」「なりきりデビル+」的目录与缩略图；不自动加入个人策略。888「スイートトラップ♡+」仍缺图，未加入。新卡手牌 OCR 和定制菜单仍需专项实机验证。
