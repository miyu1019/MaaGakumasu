# MaaGakumasu-HIF v261112.1

本次更新新增「HIF 策略」页，出牌编排取代后续卡，重做应用内更新，修复新版满体力时 SKIP 按钮无法识别导致饮料流程反复重试等战斗问题，并加入ガラクタロード后的四张强化卡；不再支持插件版汉化与 Linux 安装包。

## 更新内容

- **HIF 策略页**：左侧导航新增「HIF 策略」，在一个页面中编辑出牌优先级、获取与定制、授业换出卡、出牌编排、卡库和饮料，顶部「保存」统一写入，离开有未保存修改的页面时会询问。职业配置的导入导出移到页面顶部「职业配置」菜单，各面板说明在「使用说明」中查看。页面默认常驻，切回时不再重建，可在设置中关闭「允许 HIF 策略常驻」。
- **卡库**：按职业、计划、稀有度、类型、来源筛选全部卡牌（均可多选），点卡即可加入或移出出牌优先级、获取与定制、授业换出卡等名单，替代原来各面板的导入窗口。
- **出牌编排**：原「后续卡」改为出牌编排，以起始卡为单位设置前置、后置饮料和有序的后续候选（各自可带前后饮料），组合可设置等待回合、再次等待、出牌方式与等待时用饮。任意饮料都可设为「只在出牌编排中使用」。
- **获取与定制**：优先获取卡与技能卡定制合并为一个标签，每张卡一张卡片，同时设置「优先获取」和各定制项目的累计目标次数。
- **饮料**：全部饮料一次列出，用「单独设置」开关加入或移出领取名单，并标出被出牌编排引用的次数。
- **战斗**：
  - 适配新版满体力时 SKIP 按钮的「▷|」图标，修复关闭饮料详情后无法确认回到战斗页、反复重试后停止的问题。
  - 手牌重叠时卡名只读到右侧邻牌边缘，减少连读邻牌名字后进入详情补认。
  - 移动页点「移動」后确认已离开，点击被忽略时补点（最多 3 次）。
  - 前置饮料已用、锁定卡恰好是最后一张时，结算页可正确识别为安全页，不再误停。
  - 本战1再挑战次数用完、按钮置灰时改点「次へ」推进。
- **新卡**：加入ガラクタロード后的四张强化卡：なにかを続ける尊さ+、わずかずつの歩み+、ありのままのわたし+、認めてくれるひと+。
- **应用内更新**：设置中改为「检查并更新 HIF」与「重新安装 HIF」两个入口；安装时只替换有变化的文件，进度窗口显示步骤、总进度与当前文件；主程序退出后、尚未改动文件就中止时，会重新打开旧版并提示「更新未安装」。测试版渠道改名为 AutoBuild。可填写 GitHub Token 避免接口限流。
- **日志**：精简出牌、候选卡扫描与本战饮料的日志，统一前缀与格式。
- **前台**：升级到 MFAAvalonia v2.16.4。

## 不再支持

- 插件版汉化（含 DMM 插件汉化版）：选择这两种资源时不再显示「HIF培育」任务；官服与 DMM 不受影响。
- Linux 安装包：只发布 Windows x64。
- v261015.1 之前的配置格式：读取时忽略，并在「HIF 策略」页顶部提示所属模块，保存时去掉。

## 升级注意

- 旧版「后续卡」组合、初星黒酢组合开关与饮料的「关联卡牌」不会自动迁移，升级后请在「出牌编排」中重新设置；「HIF 策略」页顶部会提示含旧内容的模块。
- 其他个人策略、实例、连接与任务选项保留。

## 升级方式

已安装 v261105.2 可使用设置中的“更新 HIF 完整包”；本版起该入口改为“检查并更新 HIF”。

手动升级步骤：

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将完整包解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat`，导入备份。
4. 确认个人策略、实例和连接配置恢复后，再使用新版。
