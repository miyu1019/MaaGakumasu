# MaaGakumasu-HIF v261015.1

本次更新补充 10 张新强化卡及其定制项目，并改善主页面板布局、日志复制和显示设置。

## 更新内容

- 补充「競争原理+」「安定感+」「再始動+」「衝動+」「メイクアップ+」「ロマンチック+」「天使の微笑み+」「ごきげんスキップ+」「ラッシュ+」「ブースト+」的卡牌基本数据，并补齐定制菜单及次数上限。
- 为这 10 张卡加入临时截图缩略图，用于卡牌面板展示；后续待上游同 ID 图源补齐后替换。这些缩略图不用于游戏识别。
- 主页面板的位置、大小和折叠状态按实例保存，切换实例或重启后恢复；首次使用沿用原有公共布局。
- 在「设置 → 界面」新增「显示任务说明」开关，关闭后释放面板占用的空间；任务说明和实时画面开关对所有实例生效，重新开启时恢复各实例原有布局。
- 修复面板最大化、还原时改变其他面板显示状态的问题，保留隐藏状态和最大化期间修改的显示设置。
- 修复任务列表在小窗口或面板高度较小时被遮挡、无法完整滚动的问题。
- 普通日志支持鼠标选中文字后使用 Ctrl+C 复制。

## 验证情况

- 已通过：卡牌与定制目录校验、前台构建、面板布局与显示设置、任务列表布局及更新回滚检查。
- 尚未实机覆盖：本次完整包的游戏运行、新卡识别与定制操作、全部职业及异常恢复场景。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。手动升级时，请完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置，将完整包解压到新目录，再运行 `import_settings_导入设置.bat` 导入备份。确认个人策略、实例和连接配置恢复后再使用新版。
