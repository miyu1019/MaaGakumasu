# MaaGakumasu-HIF v261009.2

本版包含 v261009.1 的全部完整包更新功能，并修复检查更新看起来没有反应的问题。

## 本次修正

- GitHub 接口限流时改从本 Fork 的公开稳定发布页获取版本和更新说明，下载后仍校验 ZIP、SHA-256、版本及包内文件。
- 点击检查立即显示「正在检查」；没有新版明确提示「无更新」，失败时弹出原因。
- 自动检查进行中点击手动检查，会等待并返回结果；检查期间暂时禁用相关按钮，结束后恢复。
- 自动检查没有新版或失败时及时结束检查状态；通知显示 10 秒后关闭。

已安装 v261009.1 可通过 Maa 内完整包更新升级到本版。下面保留 v261009.1 的完整功能和首次升级说明，均适用于本版。

## 完整功能与首次升级说明（包含 v261009.1）

Windows x64 新增一键备份、导入和完整包更新，保留个人策略、实例、连接、定时任务及窗口布局。

- 复用设置中的「自动检查更新」，首次升级启用并提示，之后尊重用户选择；启动时检查一次，持续运行每 6 小时检查。
- 手动点击更新先检查版本，有新版时展示当前版本、最新版本和 Release 更新说明，确认后才下载；没有新版明确提示「无更新」。自动检查发现新版也展示说明，自动安装关闭时等待确认。
- 「自动更新 HIF 完整包」默认关闭。开启后可后台下载，等待所有实例任务结束再安装；无限循环任务须自行停止。
- 手动、自动和本地 ZIP 更新共用校验与安装流程。安装前显示可取消的 10 秒倒计时，策略窗口有未保存内容时等待保存或关闭。
- 更新程序在前台正常退出后备份配置、更换程序并恢复设置，保持安装路径及快捷方式。更新后首次启动暂不自动执行游戏任务，原启动偏好保留。
- 下载或等待期间可取消；主动退出则保留已下载包，下次启动提示继续。安装失败、启动失败或确认超时会回滚旧程序和原配置。
- 提供「恢复更新」入口，保留配置备份、旧版恢复文件和失败记录。公开模板只补缺少的文件，新增任务选项由新版补默认值；选项改名或候选重排后请核对选择。
- 附带「导出设置」「导入设置」「清除日志」工具，导出包含全部配置及布局；导入前自动备份当前设置。

**首次升级：** 在旧版完全退出后运行「导出设置」，将本次完整 ZIP 解压到新目录，运行新版「导入设置」并选择备份，再启动新版。后续支持此功能的 Windows 版本可在 Maa 内完成更新。

更新仅使用本 Fork 的稳定 Releases，前台、脚本、Python 和 MaaFramework 随完整包一起更新。首次支持自动安装的版本限定 Windows x64。默认策略仅包含集中职业，其他职业为空白模板。

验证：Windows 前台构建、回归测试和原生多实例更新策略检查通过；在独立目录实测旧版运行、等待空闲、安装、新版确认，以及启动失败后配置字节一致的回滚和旧版重启。本次未新增 MuMu 培育实测，游戏功能沿用既有版本。

下载附件包含 Windows x64 完整 ZIP 和对应 SHA-256 校验文件。
