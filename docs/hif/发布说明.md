# MaaGakumasu-HIF v261119.1

本版加入氷渡香名江的三张强化卡及卡图。应用内更新支持按文件增量下载，源码仓库的运行包同步脚本也能正确记录本地构建的版本。

## 更新内容

- **卡库**新增「柔らかな光の中で+」（SSR）、「忠義を胸に+」（SR）和「一途な従者+」（R）。三张卡均已补齐缩略图，可在「HIF 策略 → 卡库」中加入职业名单。战斗卡名识别已收录这三张卡，识别效果仍待 MuMu 实机验证。
- **应用内更新**会比对新版清单和已安装文件的 SHA-256，复用相同文件，只下载缺失或有变化的部分。界面会显示文件比对和下载进度。服务器不支持分段下载、增量校验失败或需要下载的数据超过完整包约七成时，会自动改下完整包并校验。
- **前台构建**统一了写入程序集的源码路径。在相同工具链下，同一份前台源码跨提交构建可得到相同的程序集，减少只更新卡图等资源时的下载量。
- **从源码同步运行包时**，脚本会校验并安装本次生成的 ZIP。开发分支构建记录实际 Git 提交，有未提交改动时会显示「含本地修改」，测试版渠道按提交判断更新。新版启动确认后同步脚本即可退出，失败时返回非零退出码。

## 升级注意

从正式版 `v261112.1` 升级到本版时，旧客户端会下载一次完整包。安装本版后，后续在线更新即可使用增量下载。应用内升级会保留个人策略、实例、连接配置和任务选项。

## 升级方式

已安装 HIF 的用户可在「设置 → 版本更新」选择「正式版」，点击「检查并更新 HIF」。

手动升级可按以下步骤操作。

1. 完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置。
2. 将 `MaaGakumasu-HIF-win-x64-v261119.1.zip` 解压到新目录。
3. 在新版目录运行 `import_settings_导入设置.bat` 导入备份，然后启动新版，确认实例、连接和个人策略已恢复。
