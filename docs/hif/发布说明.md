# MaaGakumasu-HIF v261013.1

本次更新修复 HIF 技能卡定制成功后误停止、卡名误匹配及部分页面恢复问题，并补充新卡目录与缩略图。

## 技能卡定制

- 修复 `届いて！+` 等卡牌的成功提示因全角、半角符号差异而被漏判的问题；按完整卡名确认成功，保留强化标记。
- 返回选卡页时确认底部返回按钮和剩余枚数，允许顶部保留当前卡的详情面板，避免正常返回后误停止。
- 返回商店后确认页面，再执行购饮、回血或结束；页面未确认时保留现场，不继续点击。
- 更新选卡格位，已确认选中的卡不重复点击；不确定的候选记录后跳过，继续检查其他卡。
- 简化定制日志，区分进入详情的尝试与实际定制；已完成卡再次出现时明确提示跳过、不重复定制，成功提示注明连续三帧确认。

## 卡名识别与流程恢复

- 换卡目标和“本領発揮”保留卡使用规范化后的完整卡名匹配，避免相似卡名或共有文字造成误匹配。
- 完善授业选项、领取奖励、饮料使用和商店页面识别；短暂过渡时重新观察，已提交的操作不重复执行。
- 改善关联出牌与饮料组合异常时的恢复，保留原有出牌优先级及使用限制；仍无法确认时明确记录原因并保留现场。
- 开启中场休息回血时，进入商店先回血，定制及已开启的购饮结束后再次回血；仅开启回血时只执行一次。

## 升级方式

已有独立 HIF 版本可使用设置中的“更新 HIF 完整包”。手动升级时，请完全退出旧版，运行 `export_settings_导出设置.bat` 备份设置，将完整包解压到新目录，再运行 `import_settings_导入设置.bat` 导入备份。确认个人策略、实例和连接配置恢复后再使用新版。
