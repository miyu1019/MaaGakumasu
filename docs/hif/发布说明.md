# MaaGakumasu-HIF v261011.1

本次更新完善 HIF 技能卡定制与授业换出规则，修复出牌、饮料、训练日行动和一战分数识别，并增加完整包更新安装进度。

> **推荐在 HIF 自动培育时关闭实时预览（实时画面）。** 演出会切换横竖屏，关闭实时预览可减少额外截图与预览连接恢复对培育的干扰。培育所需的主截图和手动截图仍然可用。

## 技能卡定制

- 支持按职业设置各定制项目的累计目标次数，按项目上限限制输入，并兼容旧配置；只有提交成功后才累计次数，已达上限的项目不再重复定制。
- 定制选卡保留卡名强化标记并采用完整匹配；点卡后核对选中角框、详情卡面和连续两帧卡名，避免卡顿时误用上一张卡的详情。
- 完整识别出目录中的非目标卡时直接跳过，减少重复识别；空白、残缺或不稳定读数继续重试。选中状态等待超时后只重试当前格一次，仍未确认则跳过并继续扫描。

## 授业换出规则

- 「授业优先换出卡」面板为每张卡增加「未定制版本优先」与「允许换出定制版本」开关，默认均开启，按职业保存。
- 授业记录卡、优先换出名单与兜底选择统一遵守逐卡规则；同名卡可优先换出未定制版本，关闭许可后保留定制版本。
- 分开记录已确认定制标记与未确认状态；未确认时按非定制卡处理，并输出对应日志。

## 饮料与训练流程

- 购饮时保护本次已选中准备购买的饮料，避免所持上限处理将其替换。
- 相谈商店及定制后购饮先检查「已兑换」标记，避免重复点击；刷新商店后重新判断格位状态。
- 同批次饮料使用后，跳过位置未变且已确认不使用的连续前缀，减少补位后的重复识别；身份不明、详情打开失败或位置变化时重新扫描，保留使用后的数量校验。
- 饮料配对目标已无可用卡时解除锁定，让其他卡继续参与出牌。
- 补充饮料领取后的相谈行动页识别，避免领取结束后卡在页面判断。
- 训练日重新核对行动页面，避免误执行休息。

## 出牌与结果识别

- 选中卡框短暂丢失时，结合当前 SELECT 状态和详情面板确认原卡位，修复「眠気」等卡选中后无法继续出牌；证据不足时继续等待，保留连续两帧确认与点击检查。
- 一战结果按玩家行的日志按钮定位分数，兼容不同偶像、排名和低分结果。

## 完整包更新

- 主程序退出后显示校验、配置备份、资源替换、配置恢复及新版启动验证进度；通过启动验证后才提示完成，失败时展示原因与回退结果。
- 完整包更新继续保留个人策略、实例、连接与界面设置；也可解压到新目录，通过导出与导入设置脚本迁移配置。
