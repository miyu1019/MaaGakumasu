# MaaGakumasu-HIF v261008.1

Windows x64 独立 HIF 培育版本。HIF 固定本战、跳过选偶像，沿用游戏中已选偶像；无需选择偶像、剧本或难度。默认集中、一次培育、不使用体力药、不跳过准备。

首次打开仅显示「一键培育」实例，任务列表只有「HIF培育」。预置维护者已确认的 HIF 选项和前台布局，省略模拟器连接信息；首次启动模板随源码维护，更新时不覆盖用户已有配置。

提供出牌优先级、优先获取卡、授业优先换出卡、饮料、技能卡定制五个配置面板。只预置集中相关策略，其他职业保留空白模板，按需要自行配置。

独立 HIF 执行器复用已连接的主控制器及其截图、输入设置；HIF 的资源和节点独立加载，任务结束后释放 Agent。

Agent 按任务启动：HIF 队列只启动 HIF Agent，连续上游任务复用主 Agent；切换到 HIF、队列结束或取消后释放闲置进程。启动失败时清理已创建的 Agent，允许之后重新启动。

达到指定培育次数后返回主界面并结束当前 HIF 任务；支持无限次数模式。

前台仅手动检查本 Fork 的 HIF 发布包，更新 HIF 和维护者已同步的上游脚本，不查询原作者仓库。更新保留用户的实例、任务选项、界面布局、HIF 策略以及前台、Python 与 MaaFramework；不兼容或更新失败时保留原版本。前台或运行时不兼容时，请将完整包解压到新目录，再复制自己的配置。

基于 MaaGakumasu v1.5.1、MFAAvalonia v2.14.0、MaaFramework 5.12.3 和 Python 3.12.9。附带 ZIP SHA-256；源码包含固定基线和完整前台补丁。

自动培育仍处于测试阶段。育成流程已在 MuMu 测试通过，指定次数结束后正常退出。
