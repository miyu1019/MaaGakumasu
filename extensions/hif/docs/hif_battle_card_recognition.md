# HIF 战斗卡牌识别

仅从 `ProduceHIFCardsFlag` 进入时启用以下识别流程。

1. 合并手牌区域内置信度至少 0.5 的 `cards` 和 `suggestions`。建议标签是卡牌属性；不会因标签切换把该牌移出手牌。`useless` 不作为可点击候选。低分框即使在模型原始结果中出现，也不作为额外卡位。
2. 重叠框在较小框至少 50% 落在另一框内时去重。13:08 样本的最右牌被拆成两个框，重叠约 54.9%，旧的 55% 阈值仍会保留假卡位；真实选中牌遮挡邻牌的回归样本仍保留邻牌。
3. 名字条 OCR 使用 HIF 总卡目录，与职业出牌优先级分开。先读取可见整宽、32 像素高的名字行，失败后保留旧裁剪兜底；建议框的光晕不作为牌底。末尾的 `+`、`++` 和全角加号归为同一身份。出现末尾强化符号时，按完整名字精确匹配；未出现时，唯一前缀可以识别，共同前缀则需要额外确认完整性。完整短名须符合 720×1280 样本的卡名居中位置、文字框右边留有至少十二像素，且末尾右侧十像素为浅色留白，否则进入模板或详情补认。这样 `アドリブ+` 及完整可见的素卡标题 `アドリブ` 可以确认身份，被裁断的裸前缀仍不能排除 `アドリブの基本`。
4. 两次整手识别一致后，缓存当前已确认的名字/模板身份，再对仍暂未识别或有歧义的牌选中查看详情。单手识别期间直接使用身份缓存，不再重跑该卡的 OCR 与模板；选中造成邻牌短暂漏框或额外框时，先按最近横向卡位关联，中心偏移过大时只接受一对一的半框重叠。暂时漏检的卡位保留身份及已尝试记录，重新检测到并关联成功后才恢复到可见手牌；未检测到的卡不参与决策或点击。实际出牌、用饮料、移动界面或换回合后清空当前缓存及暂存卡位。整手补认累计十五秒后结束，保留已有结果和暂未识别的卡进入决策，避免补认循环。
5. 详情框向上扩展，先定位浅色面板上沿，再读取顶部标题行。标题连续两次稳定、去掉末尾强化标记后，在总目录中精确匹配。不从效果正文或共同前缀猜卡名。认出但未配置优先级的牌使用该职业兜底优先级；详情识别失败或卡名未收录时也使用兜底。面板显示「兜底优先级」，日志用「暂未识别」表示身份未确认，并标注优先级来源。
6. 选中状态由目标卡下方局部 `SELECT` OCR 确认。已选中目标只进行确认出牌点击；其他目标先选中、确认，再出牌。详情补认完成后重新截图进入整手稳定判定。

## 卡顿与漏点

选中和确认出牌分成两个阶段，每阶段最多点击两次。每次点击后等待最多三秒；只有末尾两次观察明确仍未选中，或原卡仍选中且未出现出牌转换，才重试一次。选中位置、卡位关联或画面状态不明确时重新识别，不盲连点。失败的出牌尝试不会提前推进组合技或全力保留状态。

旧的选中记录需要由画面复核：连续两帧完整原手牌均无详情框、无 SELECT、无抬起卡牌时才清理。仍有详情或抬起卡牌时，即使 SELECT OCR 漏读也不重新点击。单帧 SKIP 漏检、零卡框或出牌前短暂漏掉邻牌，只重新确认手牌稳定，保留补认进度和累计时限；实际动作与可信换回合才重新开始。

选中和确认出牌的点击日志记录卡位、坐标、尝试次数、控制器 job_id、执行结果。`控制器执行成功`只证明输入任务完成，画面上的 SELECT 和详情仍需连续两帧确认。点击任务失败或异常时返回重新识别，不将其归类为游戏未选中。已有选中状态的复核会明确记录“本次未发出选中点击”；若原状态消失，则重新识别，不报告“点击未命中”。点击后的等待阶段不再打印“清理旧选中记录”，该日志只用于点击前复核。

选中前重新截图并核对卡位、完整手牌和 SKIP，避免用决策时的旧画面点击。Debug 开启且实际选中点击后仍未确认选中时，每手最多保存一组对照：`*-select-N-before.png` 是点击前画面，`*-select-N-after.png` 是等待结束画面；共用时间前缀便于核对卡位、动画和点击日志。Debug 关闭时不保存截图。

HIF 等待可出牌状态时，血条识别成功会清零退出计数，只有连续漏读才判断退出；单次等待最长十五秒，到限后交回状态识别。停止任务时先检查停止标志，再截屏或操作。

连续两次识别到“手札のスキルカードが0枚です”才确认空手。SKIP 可见但持续十五秒没有可靠卡框、也未确认空手时，按用户选择点击 SKIP。

## 为什么频繁复核

13:08–13:14 的最新一轮正常结束，记录 29 次确认出牌、16 次详情补认以及 9 次回合 OCR 备用复核。详情补认中 8 次为 `アドリブ`：总目录同时包含 `アドリブ` 和 `アドリブの基本`，旧逻辑忽略末尾强化符号，把完整短名也判成共同前缀；旧名字条的 75% 宽度还会截断居中的短名，并混入上一行属性。实际出牌后卡位重新排列，按设计清空身份缓存，使这些失败再次触发详情补认。

两帧整手稳定检查属于正常决策前检查，继续保留。详情补认只在名字和模板不能可靠确认身份时触发；遮挡导致共同前缀无法排除时仍须补认。

回合数的 9 次备用复核都发生在“4”：常规文字检测裁出的窄框使 OCR 不命中，固定数字区直接识别则成功。HIF 现在优先直接读取固定数字区（严格整数匹配、0.9 阈值），失败后才尝试文字检测；保留 1/7 笔画纠错和相邻回合跳变约束。其他路线保留原来的读法顺序。

13:29–13:34 本战2正常结束，记录二十九次出牌、四次详情补认、五次选中漏点后重试恢复。剩余补认中三次是未强化的 `アドリブ`；完整素卡标题现在通过居中与留白校验后精确匹配。另一次 `タイミングの基本` 的 OCR 原文含误识别字符，仍通过详情识别。选中牌遮挡邻牌期间可能出现四框/五框波动，继续要求两帧整手一致后决策。

该轮结算过场又产生了十一次回合补读 `1`，对应时段的原生日志确认 SKIP 模板均未命中。HIF 主循环现在只在 SKIP 可见后读取回合数；结算判断和最后回合过场跳过仍先行处理，防止将背景文字当成回合数字。

同日 13:08–13:14 的十二张真实诊断截图共四十四张可见牌，使用实际 MAA 模型比较名字条读法：旧读法有十六张无法确认，新读法只剩三张被邻牌遮挡的 `アドリブ`，已确认的四十一张均符合样本身份。该统计只比较名字条识别，不将模板兜底和动态战斗效果计入。十二张截图的回合数均在第一次读取时正确命中，不再调用备用复核。相关 147 项测试通过。
